## D-001 — Переезд по D-001 системы (2026-10-01)
**Context:** проект GLTranslate жил в `F:\Programming\csharp\_libraries\GLTranslate` с документацией внутри кода (`Constitution.md`, `ClassRule.md`, `Dictionary.md`) и ветвью `master`.
**Options:** (а) пересоздать репозиторий с нуля одним коммитом, как требует миграция по умолчанию; (б) перенести репозиторий вместе с историей.
**Decision:** (б) — по слову владельца история 52 коммитов сохраняется. Репозиторий скопирован целиком, поверх добавлены два коммита: раскладка `src/`, `tests/` и перенос заметок; ветвь переименована `master` → `main`; решение названо `GLAZOV.M.TRANSLATE.slnx`; репозиторий GitHub переименовывается в `GLAZOV.M.TRANSLATE`. Документы из дерева кода перенесены сюда, в `docs/Правила автора/`; в самом репозитории они остаются только в старой истории.
**Consequences:** старые документы видны в истории кода (они не содержат следов GES, ролей, ИИ — проверено поиском по сообщениям коммитов); история сохранена целиком; оригинал в `_libraries\GLTranslate` не тронут до подтверждения владельцем.

## D-003 — Решения автора, восстановленные из кода и свода правил (2026-10-01, реконструкция)
Восстановлено по `Constitution.md` и коду; даты и точные поводы неизвестны.
- Домен первичен: ISO, BCP и идентификаторы провайдеров описывают домен, но не определяют его (INV-001).
- Идентификаторы и коды — объекты-значения; коллекции — `CodeSet<T>` и `EntitySet<T>`, неизменяемые.
- Один проект на провайдера и по проекту тестов на модуль; общее вынесено в `Providers.Common`.
- Данные языков создаются генераторами в `tools/`, а не пишутся вручную.
- Целевая платформа — .NET 10.
