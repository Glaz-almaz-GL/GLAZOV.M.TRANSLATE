## D-001 — Переезд по D-001 системы (2026-10-01)
**Context:** проект GLTranslate жил в `F:\Programming\csharp\_libraries\GLTranslate` с документацией внутри кода (`Constitution.md`, `ClassRule.md`, `Dictionary.md`) и ветвью `master`.

**Decision:** (б) — по слову владельца история 52 коммитов сохраняется. **Consequences:** старые документы видны в истории кода (они не содержат следов GES, ролей, ИИ — проверено поиском по сообщениям коммитов); история сохранена целиком; оригинал в `_libraries\GLTranslate` не тронут до подтверждения владельцем.

## D-003 — Решения автора, восстановленные из кода и свода правил (2026-10-01, реконструкция)
Восстановлено по `Constitution.md` и коду; даты и точные поводы неизвестны.
- Домен первичен: ISO, BCP и идентификаторы провайдеров описывают домен, но не определяют его (INV-001).
- Идентификаторы и коды — объекты-значения; коллекции — `CodeSet<T>` и `EntitySet<T>`, неизменяемые.
- Один проект на провайдера и по проекту тестов на модуль; общее вынесено в `Providers.Common`.
- Данные языков создаются генераторами в `tools/`, а не пишутся вручную.
- Целевая платформа — .NET 10.

## D-005 — Google: второй провайдер на batchexecute (2026-10-01)
**Context:** старый вход Google (`translate_a/single`) работает только по HTTP/2 и держится на запасном пути; исследование XUnity показало, что внутренний вызов страницы `batchexecute` работает без токена, куки и особой версии HTTP.
**Options:** заменить старый движок; добавить второй провайдер рядом; выбор движка настройкой одного провайдера.
**Decision:** отдельный провайдер `GoogleBatchExecuteTranslationProvider` (имя `Google.BatchExecute`), старый не тронут: два независимых пути, у клиента выбор. Адрес сервиса, имя вызова, метка сборки и предел длины текста — параметры `GoogleBatchExecuteOptions` с проверкой (инвариант 15 системы). Пробел между предложениями, который сервис роняет, восстанавливается по исходному тексту.
**Consequences:** есть запасной путь, если один из двух перестанет работать; один запрос — один текст до 5000 знаков (пакетная склейка строк не делалась); озвучивание (`jQ1olc`) и подсказки (`AVdN8`) того же адреса не реализованы — отдельные записи при нужде.

## D-006 — Papago: провайдер перевода и транслитерации (2026-10-01)
**Context:** Papago нет в библиотеке; способ XUnity (подпись HMAC и версия из `main.*.chunk.js`) устарел, сайт переписан на Next.js, но `/api/text/translation` отвечает без подписи.
**Decision:** новый проект `Providers.Papago`: `PapagoTranslationProvider` и `PapagoTransliterationProvider` (романизация исходного текста берётся из поля `tlitSrc` ответа на перевод в английский). Адрес, предел длины и язык замечаний — `PapagoOptions`. Список языков не зашит: пару, которой нет, сервис отказывает сам (400 с кодом и причиной в сообщении).
**Consequences:** словарь, озвучивание, определение языка (`/api/langs/dect`), перевод изображений и целая транслитерация перевода (`tlit`) не реализованы; способ может сломаться при очередной переписи сайта — как уже случилось.

## D-007 — Bing: транслитерация уже читается, признак LLM не берётся (2026-10-01)
**Context:** обзор XUnity отметил, что ответ Bing несёт транслитерацию и признак `usedLLM`.
**Decision:** транслитерацию наш `BingTransliterationProvider` уже читает (`inputTransliteration`); признак `usedLLM` не берётся — в модели результата для него нет места, и решение о расширении модели — отдельное.
**Consequences:** пункт обзора закрыт без правок кода.
