| Термин         | Значение                                                                                                |
| -------------- | ------------------------------------------------------------------------------------------------------- |
| **Client**     | Публичная точка входа для выполнения определённой операции (например, перевода или определения языка).  |
| **Provider**   | Реализация поддержки конкретного сервиса (Google, Bing, DeepL и т.д.).                                  |
| **Engine**     | Внутренний компонент провайдера, выполняющий бизнес-логику операции. Не является частью публичного API. |
| **Request**    | Неизменяемая модель, описывающая параметры одной операции.                                              |
| **Result**     | Неизменяемая модель, содержащая результат выполнения операции.                                          |
| **Model**      | Предметная сущность, независимая от конкретной операции или провайдера.                                 |
| **Options**    | Конфигурация поведения клиента или отдельной операции.                                                  |
| **Capability** | Возможность, поддерживаемая провайдером (например, словарь, транслитерация, примеры использования).     |
