## Что подтверждено живыми запросами

### Google batchexecute — подтверждено, что работает проще, чем у XUnity
- Достаточно одного POST на `https://translate.google.com/_/TranslateWebserverUi/data/batchexecute`, без предварительной загрузки главной страницы и без куки.
- `f.sid` может быть любым числом, `bl` может быть пустым или старым значением XUnity (`boq_translate-webserver_20210323.10_p0`), HTTP/1.1 принимается. Страница сегодня отдаёт другой `cfb2h` (`boq_identityfrontenduiserver…`), он для этого не нужен.
- Тело: `f.req=` + urlencode(`[[["MkEWBc","[[\"<текст>\",\"<src>\",\"<dst>\",true],[null]]",null,"generic"]]]`) + `&`. Лишний аргумент между текстом и языком даёт ошибку `[3]` — важно не добавлять.
- Ответ: после префикса `)]}'` строка длины и JSON; перевод — по пути из прошлого исследования, предложения с исходником в позиции 6. Определённый язык источника тоже приходит (`"ja"`).
- Проверено: русский, японский (`auto`), немецкий, французский; три строки в одном тексте; 4200 символов — работает; 9000 — отказ `[3]` (порог между ними, обычно 5000).
- **Новое для нас — два других RPC того же адреса, тоже без сессии:**
  - `jQ1olc` — озвучивание: аргументы `["Hello world","en",null,"null"]`, в ответе base64 mp3 (проверено: ~13 КБ).
  - `AVdN8` — подсказки/автодополнение: `["Hello","en","ru"]` → список пар `["hello","привет"]`, `["hello how are you","Привет, как дела?"]`.
- Не нашлось: транслитерация и словарь в этом виде запроса — для `MkEWBc` с базовыми аргументами они пустые; `rPsWke` и `exi25c` с моими аргументами отказали (аргументы неизвестны).

### Papago — API сменился, работает без токена
XUnity берёт версию из `main.*.chunk.js` и подписывает запрос HMAC-MD5; сайт теперь на Next.js, такого файла нет, старые адреса `/apis/n2mt/…` закрывают соединение. Сегодняшние адреса (из `API_URL` в скриптах сайта):
- `POST /api/text/translation` и `/api/text/translation/instant`, тело `deviceId=<guid>&locale=en&dict=false&dictDisplay=30&honorific=false&instant=false&paging=false&source=en&target=ko&text=…` — **проверено: 200 без подписи**; ответ: перевод, транслитерация по словам (`tlit`: `token`/`phoneme`), тип движка (`NSMT`/`PRETRANS`) и вероятности определения языка (`langDetection`).
- `POST /api/langs/dect` (`query=…`) — определение языка, **проверено**: `{"langCode":"en"}`.
- Есть, но не проверялись: словарь `/api/dictionary/search`, голос `/api/tts/makeID` + `/api/tts/{id}`, рукописный ввод `/api/ext/hwr/list/{lang}`, перевод изображений `/api/image/translation`, глоссарии (нужен вход), `/api/tlit/wsep` и `/wtp` (на моём запросе 400).
- Языки у XUnity: en, ko, zh-CN, zh-TW, es, fr, ru, vi, th, id, de, ja, hi, pt; для hi и pt — только в паре с английским.

### DeepL
- Веб (`www2.deepl.com/jsonrpc`): метод `LMT_handle_jobs`, исходник кладётся в поле `raw_en_sentence`, рядом `raw_en_context_before/after` — **контекст соседних строк** — единственная интересная идея, остальное блокируется: 429 с кодами `1042911/1042912` на самом первом запросе. Не рабочий путь.
- API: официальный, ключ, `api-free.deepl.com` для бесплатных ключей, `v2/translate` (`split_sentences=1`), список языков `v3/languages?resource=translate_text` — XUnity кеширует его сутки. Это разумный провайдер, если у владельца есть ключ.

### Bing — наш уже есть, но ответ богаче, чем у XUnity
`ttranslatev3` по ключу и токену со страницы вернул перевод, транслитерацию (`transliteration.text`, `script: Latn`), определённый язык и признак `usedLLM: true` (перевод языковой моделью). Если наш `Bing` их не читает — это дешёвое расширение (UNVERIFIED: наш код не сверялся).

## Идеи из самого XUnity, не про сервисы
- Пакетность: несколько текстов склеиваются через `\n` в один запрос и режутся обратно по числу строк; несовпадение — отказ. Лимиты: Google, Papago, Bing, Watson — 10 текстов; DeepL — 25.
- Защита: случайные паузы (DeepL 2–6 с, не меньше 1–3), сброс сессии через случайные 75–125 запросов, ответ 429 → сброс и ошибка.
- Расширения: «внешний процесс» для переводчиков, не умещающихся в библиотеку; настраиваемый адрес сервиса (`ServiceUrl`).

Каждый пункт — задача по карточке с проверкой на живом сервисе и тестами по записанным ответам; параметры (адреса, версии, лимиты, паузы) — в настройках провайдера (инвариант 15 системы).

## Оговорки
- Все живые проверки — один день и один IP; сервисы могут начать блокировать при частых вызовах (Google и DeepL уже блокировали такие запросы в прошлом).
- Внутренние API сайтов не документированы и могут измениться без предупреждения — как уже случилось с Papago.
