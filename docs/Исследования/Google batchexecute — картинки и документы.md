# Исследование — можно ли переводить фото и документы через batchexecute

Дата: 2026-10-01. Роль: ПРОГРАММИСТ. Файлы кода не менялись.
Метод: страница translate.google.com открыта во встроенном браузере (с согласием на куки), загрузка файла в нужную вкладку и перехват её запросов; затем те же запросы из PowerShell.

## Короткий ответ

**Путь есть, перевода пока не получили.** Сайт делает и для картинок, и для документов тот же вызов `batchexecute`, но с другими именами вызова, и принимает файл целиком прямо в запросе. Оба вызова отвечают без сессии и токена. Однако в этой проверке оба вернули тот же файл без изменений, а страница в это время показывала «API занят…». Что перевод бывает, не подтверждено; поэтому провайдеры картинок и документов на этом не писались.

## Что установлено

| | Картинки | Документы |
|---|---|---|
| Вызов | `WqWDPb` | `LBEnTe` |
| Аргументы | `[["<base64 файла>","image/png"],"<исходный язык>","<целевой язык>"]` | `[["<base64 файла>","<mime>"],"<исходный>","<целевой>"]` |
| Ответ | `[["<base64>","image/png"]]` | `[["<base64>","<mime>"]]` |
| Форматы сайта | JPEG, PNG, WebP | PDF, DOCX, PPTX, XLSX |
| Сессия, куки, `bl` | не нужны (проверено без них) | не нужны (проверено без них) |
| Что вернулось | то же самое изображение, побайтно (русский, японский и английский тексты на белом) | тот же файл, побайтно (маленький DOCX, 936 байт) |

- Из страницы файл уходит в теле запроса целиком, то есть большой файл — большой запрос; предел размера не измерялся.
- Страница в обоих случаях показала рабочий интерфейс («Скачать перевод» для документа), а в списке кнопок страницы была подпись «API занят…» с кнопкой «Повторить». Вероятная причина — перегрузка или ограничение серверной части для моего адреса/запроса: сервис возвращает вход как есть.
- Для картинок после ответа страница лишь запросила `blob:` — то есть показала то, что пришло в ответе; никакого второго обращения за «настоящим» результатом нет.

## Что неизвестно

- Бывает ли в ответе иной файл, чем на входе: на синтетических картинках (текст на белом, нарисованный программой) и маленьком DOCX — нет. Фотографию с текстом и настоящий документ не проверяли.
- Не зависит ли результат от входа в аккаунт Google.
- Размер файла, после которого сервис отказывает.

## Что предлагаю

1. Повторить проверку на реальной фотографии с текстом и документе в несколько страниц, в другое время и, если возможно, с другого адреса — это дёшево: скрипт уже есть.
2. Если перевод придёт — сделать два провайдера на готовых интерфейсах `IImageTranslationProvider` и `IDocumentTranslationProvider`; в параметры — имена вызовов и предел размера (инвариант 15 системы); в ответе проверять, что файл изменился, а неизменённый — отдавать как отказ «сервис вернул файл без перевода».
3. Если не придёт — оставить как есть: для картинок у библиотеки уже есть Yandex Cloud, Google Cloud Vision и Baidu.
