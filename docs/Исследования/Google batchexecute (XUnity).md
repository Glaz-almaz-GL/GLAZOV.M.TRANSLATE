Источник: github.com/bbepis/XUnity.AutoTranslator (клон без `.git` — `Reference/` код-репозитория, в git не входит). Файл — `src/Translators/GoogleTranslate/GoogleTranslateEndpointV2.cs` (старый вариант — `GoogleTranslateEndpoint.cs`, на `translate_a/single` с токеном, как у нас сейчас).

**Состояние: разбор кода + живая проверка того же дня (см. `Переводчики XUnity — обзор и проверка.md`).** Запрос работает и проще, чем у XUnity: без куки, со случайным `f.sid`, с пустым `bl`, по HTTP/1.1. Всё, что ниже о подготовке сессии и версии сборки, — описание XUnity, а не необходимость.

## Как устроен запрос

Тот самый внутренний RPC веб-страницы translate.google.com.

1. **Подготовка (раз в 75–125 переводов, случайно).** GET `https://translate.google.com` с куками в общем `CookieContainer`; из HTML вырезается значение после `FdrFJe":"` — это `f.sid` (число). Не нашлось — берётся случайное `long`. Тем же GET приходят куки сессии. Случайно выбираются и `_reqid` (0–100000, дальше +100000 на каждый запрос) и `Accept-Language` из набора (пусто, `en-US,en;q=0.9`, `en-US`, `en`).
2. **Перевод.** POST `https://translate.google.com/_/TranslateWebserverUi/data/batchexecute?` + query:
   `rpcids=MkEWBc`, `f.sid=<число>`, `bl=boq_translate-webserver_20210323.10_p0` (версия сборки сайта, настраиваемая), `hl=en-US`, `soc-app=1`, `soc-platform=1`, `soc-device=1`, `_reqid=<число>`, `rt=c`.
3. **Тело** `application/x-www-form-urlencoded`: `f.req=` + urlencode от `[[["MkEWBc","[[\"<текст>\",\"<src>\",\"<dst>\",true],[null]]",null,"generic"]]]` + `&`. Текст двойно экранируется как JSON-строка (внутренний массив — это строка внутри строки). Несколько текстов склеиваются через `\n` в один запрос (до 10).
4. **Заголовки:** User-Agent браузера (Chrome/Win10), `Referer: https://translate.google.com/`, `Origin: https://translate.google.com`, `X-Same-Domain: 1`, `DNT: 1`, `Accept: */*`, `Content-Type: application/x-www-form-urlencoded;charset=UTF-8`.
5. **Язык:** `zh`/`zh-Hans` → `zh-CN`, `zh-Hant` → `zh-TW`; источник может быть `auto`.

## Как разбирается ответ

Ответ — «кусочный» формат `rt=c`, не JSON:
- Отбросить первые 6 символов (`)]}'` + перевод строки + пустая строка — защитный префикс).
- Дальше строка с числом N (длина), затем N символов — первый кусок; остальные куски не нужны.
- Кусок — JSON-массив; `[0][2]` — **строка**, внутри которой лежит ещё один JSON. Её надо развернуть (убрать кавычки, снять экранирование) и разобрать снова.
- Внутри: `[1][0][0][5]` — массив предложений; в каждом `[0]` — переведённый текст, `[1]` — запасные варианты перевода. Предложения склеиваются через `\n`, потом режутся обратно по числу строк исходных текстов (при несовпадении — отказ «неверное число переводов»).

## Что ломается в таких запросах (по самому коду)

- `bl` (версия сборки сайта) и `rpcids` зашиты как значения по умолчанию, но вынесены в настройки: автор ждёт, что они устареют. В нашей библиотеке это нужно как параметр с умолчанием (инвариант 15 системы).
- Индексы ответа (`[1][0][0][5]`) — позиции в недокументированной структуре; любое изменение Google их сдвигает. Нужна проверка формы и внятный отказ, а не `IndexOutOfRange`.
- Разбор ответа в XUnity вручную и хрупкий: срезается по числу символов (считается в UTF-16 кодовых единицах, как в JS), экранирование снимается самописным методом. В .NET то же делает `System.Text.Json` (двойной разбор).
- Куки и `f.sid` нужны для устойчивой работы: без подготовки код падает на случайное значение, но продолжает — значит, сервис, вероятно, терпит случайный `f.sid`, но это не проверено.

## Сравнение с нашим движком

Наш `GoogleTranslationEngine` ходит на `translate.googleapis.com/translate_a/single?client=gtx` по HTTP/2 (HTTP/1.1 даёт 429 — записано в коде). batchexecute — другой вход: адрес сайта, куки-сессия, формат «кусочками». Различия:

| | translate_a/single (наш) | batchexecute (XUnity V2) |
|---|---|---|
| Ответ | чистый JSON (`dj=1`) | кусочный формат с JSON внутри JSON |
| Сессия | не нужна | GET главной страницы, куки, `f.sid` |
| Параметры версии | нет | `bl`, `rpcids` — устаревают |
| Пакетность | один текст | до 10 текстов за раз склейкой |
| Транслитерация | `dt=rm` | не берётся в этом коде |

Что даёт batchexecute: тот же путь, что у самого сайта, поэтому ограничения 429 на HTTP/1.1 к нему могут не относиться (UNVERIFIED), и пакетный вызов. Чего в нём нет: транслитерации и словаря в извлечённом коде — только основные предложения и варианты.
